Claude Code 安装与使用指南（Mac & Windows）

前言

Claude Code 是 Anthropic 推出的 AI 编程助手 CLI 工具，本文介绍 Mac 和 Windows 两个平台的完整安装流程。

Mac 安装

第一步：安装 Homebrew

Mac 推荐通过 Homebrew 来管理软件包。官方安装脚本在国内访问较慢，建议使用国内镜像源安装：

Windows 安装

第一步：安装 Git

前往 git-scm.com 下载安装包，一路默认安装即可。

第二步：安装 Node.js

推荐使用 winget 安装最新版本：

第三步：安装 Claude Code

客户端选择

安装完成后，有两种使用方式：

方式 工具 特点
CLI（命令行） CC Switch 轻量，支持多 Agent 管理
GUI（图形界面） Tokenicode 轻量级图形界面，配合 CC Switch 做 Agent 管理

推荐组合： Tokenicode + CC Switch，既有友好的图形界面，又能灵活管理多个 Agent。

总结

平台 核心依赖 安装命令
Mac Homebrew + Node.js 国内镜像脚本
Windows Git + Node.js winget + npm

两个平台最终都通过 npm install -g @anthropic-ai/claude-code 完成 Claude Code 的安装，步骤简洁，上手门槛低。
